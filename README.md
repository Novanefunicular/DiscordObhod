>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам, после чего удаляет их и помещает в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо выключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений предпочтителен этот вариант; если вы не понимаете последствия настройки, отключите детектирование PUA.

## ⚙️Использование

1. Активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите провайдера, отличного от "Поставщика по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован.
    * Windows 11 позволяет включить Secure DNS в параметрах самой системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Novanefunicular/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, это действие не требуется.

4. Распакуйте архив в каталог без кириллицы и специальных символов в пути.

5. Запустите нужный сценарий:
    * Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для установки автозапуска: **`service.bat`** -> `Install Service` -> выберите подходящую стратегию.

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (`ALT`, `FAKE` и другие), пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск служб (`services.msc`).</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб.
  - **`Check Status`** - просмотр состояния обхода, автозапущенной стратегии и WinDivert.
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  После изменения необходимо перезапустить стратегию.  
  В скобках показывается, включена ли функция.
  - **`IPSet Filter`** - изменение режима обхода ресурсов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret доступен, а с ним перестаёт работать.  
  В скобках отображается режим:
    - `none` - ни один IP не проверяется;
    - `loaded` - IP сверяется со списком;
    - `any` - под фильтр попадает любой IP.
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений.
  - **`Replace active fakes`** - замена текущего фейка на другой файл из `bin`.
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** - ручной поиск обновлений.
  - **`Run Diagnostics`** - проверка распространённых причин неисправности zapret.  
  В конце можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной остановке работы приложения.
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - проверка сайтов из `utils/targets.txt`;
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После `general*` ничего не появляется

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться `winws.exe`, отвечающий за обход. Если этого не произошло, обратитесь к [#522](https://github.com/Novanefunicular/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:

- Скопируйте весь текст из открытого блокнота.
- Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора.
- Вставьте скопированное содержимое в конец файла или замените ранее добавленный аналогичный блок.
- Сохраните файл и проверьте соединение. Если результата нет, убедитесь, что изменения действительно сохранены.

#### Работоспособность не гарантируется. При отсутствии результата используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Novanefunicular/tg-ws-proxy) или публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Рабочая стратегия может со временем перестать работать.**
> После обнаружения конкретная стратегия иногда теряет эффективность. В репозитории собрано много вариантов обхода; если готовые настройки не подходят, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и проверьте сообщения об ошибках.
- Убедитесь, что ресурс добавлен в списки доменов или IP-адресов.
- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/Novanefunicular/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить zapret

- Сохраните добавленные вами ресурсы и настройки.
- Перезагрузите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце подтвердите действие клавишей Y.
- Удалите старую папку zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/Novanefunicular/zapret-discord-youtube/releases), файл вида `zapret-discord-youtube-...`.
- Нажмите правой кнопкой по архиву, откройте свойства и при наличии отметки "Разблокировать" выберите её, затем нажмите "Применить" и "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов.
- Поочерёдно проверьте различные `general`-скрипты. Если ресурс недоступен, закройте программу через значок замка в панели задач и попробуйте следующую стратегию.
- После выбора подходящей стратегии установите её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

Инструкция по этой ситуации находится [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался в службах

1. Найдите имя службы в командной строке Windows (`Win+R`, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше сервис уже работал.
- См. также [#251](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно используйте её.
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Novanefunicular/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Novanefunicular/tg-ws-proxy).
- Либо используйте бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую невозможно.

Обычно следует обновить ipset через `service.bat` и включить `Game Filter`. Если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Novanefunicular/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Ответа на проблему нет

Опишите её в [issues](https://github.com/Novanefunicular/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса можно указать в следующих файлах:

- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но отдельный домен фильтровать не нужно.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети-исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
